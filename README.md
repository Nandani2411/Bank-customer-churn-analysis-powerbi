# 📊  Bank Customer Churn Analysis Dashboard
## 📌 Project Overview

This project focuses on analyzing Bank customer churn using an interactive Power BI dashboard.

The objective is to understand customer behavior, identify factors associated with churn, and provide data-driven recommendations to improve customer retention.

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Excel
- Data Cleaning
- Data Visualization

## 🔍 Key Insights

- Medium-risk customers showed the highest churn rate at **26.4%**.
- Inactive customers showed greater retention risk.
- Churned customers had a slightly higher average balance than retained customers.
- Lower credit-score customers showed a higher tendency toward churn.
- Product usage does not necessarily guarantee better customer retention.

## 💡 Business Recommendations

- Prioritize medium-risk customers with proactive retention campaigns.
- Re-engage inactive customers through personalized communication and offers.
- Focus on product suitability rather than simply increasing the number of products.
- Monitor lower-credit-score customers for early signs of churn.
- Use multiple customer attributes together to identify customers at risk of churn.

## 🎯 Project Objective

The goal of this project is to transform customer data into meaningful business insights and support data-driven customer retention strategies.
